The 3-minute talk track

If judges give you three minutes and one browser tab, run exactly this. It hits all three refusals with one demonstration each.

0:00

Open on the Dashboard, don't touch anything yet

Say: "This is not an AI agent — it's a trust harness." Point at the LLM Zero Decision Authority badge. Add, proactively: "the reasoner is a deterministic mock right now, no API key — every guarantee you'll see is enforced by the harness, not the model."
0:30

Click Healthy scene → Run check

Let the Live Execution panel animate through all six stages without talking over it. Land on AUTO_OPTIMIZE, 100%, single-digit milliseconds. Say: "nine sensor readings, all trusted, no contradiction — automation continues."
1:15

Click Risk Anomaly scene → Run check

Set it up first: "cooling reports ON while cargo is 11.5°C — those two facts can't both be true." Then narrate in order: correlation catches it before the model reasons → the model reasons anyway and calls it HIGH risk → the verifier checks that against the evidence → confidence falls 100%→78% → the Controller reaches CRITICAL_HALT. Land the line: "notice what didn't happen — the model didn't decide, it produced an opinion."
2:15

Point at the pending action card → Approve

Say: "halting is human-tier — it doesn't execute, it waits for a person." Click Approve, point at the three timestamped rows (requested / approved / executed).
2:45

Close

Say slowly, one beat between each: "Agents investigate. The Critic challenges. Deterministic policy decides." Stop talking.
Got 60 seconds instead? Cut to just steps 2 and 3 — the healthy run and the halt. That alone proves both refusals that matter most.

Questions judges actually ask

The reasoner is mocked — does any of this hold with a real model?

Yes — every guarantee is enforced on the harness side, not the model side: strict schema validation, the verifier's checks, the gate, the controller's fixed rule order. Point at backend/.env's OPENROUTER_API_KEY — same script, real model, identical refusals.

What if the model is just right, and the harness blocks a good action?

That's the intended trade — it's asymmetric on purpose. Worst case here is a human looks at a screen. Worst case for "let the model act directly" is spoiled cargo.

Why doesn't the model just report its own confidence?

Because a self-reported number isn't an observation of anything. The schema literally forbids a confidence field — it's computed from what the harness can independently verify.

How is "the agent can't act" actually enforced?

By absence, not permission. The agent code has no import of the actions module at all — there's no reference to call, so a misconfigured permission check isn't even the failure mode being tested for.

What does "execute" actually do?

Creates an immutable escalation record. Nothing touches a real fleet system — that's flagged in code as a future integration point, deliberately out of scope for what's being proven today.

Two policy packs isn't really "domain-independent," is it?

Fair, and the claim is narrower than that: the gate, correlation engine, verifier and controller contain zero cold-chain-specific logic. Swapping the pack changes required signals and the risk logic without touching any of those four files.

Don't say / Do say

Corrections a technical judge will catch instantly if you phrase it wrong.

"The AI decides when to halt."
The AI produces a risk assessment. The Controller decides.
"Confidence drops to zero when an agent dies."
It drops to the share of expected evidence that survived — 56% with one agent down, not 0%.
"The halt means 100% confidence something's wrong."
The halt run reads 78% — a contradiction lowers confidence, it doesn't raise it.
"The system executes a cooling override."
It creates an escalation record, after a human approves.
"$85,000 of cargo was saved."
That figure is the counterfactual card's illustration, not a measurement.
